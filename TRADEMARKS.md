# The schneidi name and logo

The code of schneidi is free software ([GPL-3.0](LICENSE)). The name "schneidi" and the schneidi logo are not part of
that license. The rules below keep it clear which builds are official, so nobody gets a copy with ads or malware
under the schneidi name.

## Fine without asking
- Talking about schneidi: articles, videos, tutorials, reviews, comparisons.
- Packaging schneidi from the unmodified source under its name (Linux distributions, Flatpak, AUR, F-Droid …). Small
  changes needed for packaging or security fixes are fine, as long as the package carries no ads, in-app purchases or
  price tag, and it is clear where it comes from.
- Forking schneidi under a different name and logo.

## Needs written permission
- Publishing a modified version, or any version with ads, in-app purchases or a price, as "schneidi" or with the
  schneidi logo. This includes app stores (Google Play, App Store, Microsoft Store …).
- Names or logos that can be mixed up with schneidi (for example "schneidi Pro" or "Schneidi Editor").
- Making a version look official or endorsed when it is not.

## Official builds
- Releases on [github.com/OnkelTheorie/schneidi](https://github.com/OnkelTheorie/schneidi/releases).
- App store listings published with permission of the maintainer.

Questions or requests: open an issue on GitHub.
